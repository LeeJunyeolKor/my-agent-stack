# ADR 0001: 이식 가능한 카탈로그와 결정론적 설치 도구

- 상태: 채택됨
- 날짜: 2026-09-04

<a id="context"></a>
## 배경

이 프로젝트는 작성자가 에이전트와 일하는 방식을 보여주는 것과, 선택한 워크플로를 다른 회사·도구 스택·컴퓨터로 옮길 수 있게 하는 것이라는 두 가지 목적을 충족해야 합니다. 카탈로그만으로는 설치 상태를 재현할 수 없습니다. 범용 실시간 자동화 플랫폼을 만들려면 핵심 모델을 입증하기도 전에 인증, 프로바이더 API, 스케줄링, 더 넓은 신뢰 범위가 필요합니다.

<a id="decision"></a>
## 결정

공개에 맞게 정제한 기계 판독형 카탈로그와 외부 패키지 의존성이 없는 로컬 설치 도구를 만듭니다.

- 스킬과 자동화는 제품 이름이 아니라 필요한 기능에 의존합니다.
- 프로필에서 에이전트, 프로바이더, 구성 요소를 선택합니다.
- 계획 생성과 파일 쓰기를 분리합니다.
- 스킬은 문서화된 대상 디렉터리로 복사합니다.
- 자동화 레시피는 비활성 상태로 복사하며 예약하지 않습니다.
- 설치된 모든 파일을 SHA-256 영수증에 기록합니다.
- 제품 커넥터와 런타임 활성화는 이후로 미룹니다.

<a id="consequences"></a>
## 결과

첫 버전은 포트폴리오, 재현 가능한 구성, 안전한 설치 기반으로 사용할 수 있습니다. 아직은 프로바이더를 선택해도 연동이 실제로 동작하지 않으며, Agent Skills를 복사했다는 사실만으로 에이전트 간 동작 동등성이 입증되지는 않습니다. 이러한 한계는 CLI 출력과 문서에 계속 명시해야 합니다.
