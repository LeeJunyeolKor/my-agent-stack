# ADR 0002: 기존 카탈로그에서 Codex 패키지 생성

상태: 채택

0.3 추가 결정: 코드 설명에 필요한 단일 HTML 템플릿을 스킬의 `assets/explainer.html`에 둔다. `code-explainer`의 해당 경로만 빌드 허용 목록에 추가하고 HTML 앵커·상대 참조를 검사한다. 별도 플러그인 템플릿 원본이나 CDN·인증 의존성은 만들지 않는다.

`skills/`와 구성 요소 매니페스트를 계속 원본으로 사용한다. 별도의 플러그인 스킬 원본은 만들지 않는다. 기존 선택형 설치는 그대로 제공하고 하나의 로컬 마켓플레이스와 플러그인을 생성하는 CLI 명령을 추가한다.

패키지는 고정 경로 `dist/codex`에 생성하고 Git에서 제외한다. 설치 도구의 계획·충돌 감지·검증 후 교체 방식을 재사용한다. 소스 허용 목록, 상대 참조, 전체 포함 파일과 해시를 검사한다. 본문은 변경하지 않고 복사하며 manifest의 캐시 버전만 내용 해시로 생성한다.

이 선택은 빌드 없는 GitHub 직접 설치를 제공하지 않는다. 로컬에서 생성·검증·등록한 뒤 사용하는 흐름을 우선한다. 다른 에이전트의 설치 폴더 계약과 기존 프로필 버전은 유지한다. 공유 지침은 매니페스트의 dependencies로 설치하고 이름 변경은 중앙 별칭으로 해석한다.
