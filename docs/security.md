# 공개 및 설치 안전성

커밋한 모든 바이트가 공개된다고 간주합니다.

<a id="publication-boundary"></a>
## 공개 경계

다음 항목은 커밋하지 않습니다.

- 실제 계정에 연결된 자격 증명, 토큰, 인증 헤더, 비밀 값 이름
- 사용자의 절대 경로, 비공개 도메인, 티켓 식별자, 내부 저장소 위치
- 복사한 회사 문서, 소스 코드, 장애 자료, 고객 데이터, 업무 결과물
- 비공개 구성 요소 ID 또는 그 출처를 드러내는 매핑
- 재배포 권한을 확인하지 않은 서드파티 스킬

가상의 예시를 사용합니다. 모든 구성 요소는 출처와 라이선스를 선언하고 `sanitized: true`로 표시해야 카탈로그에 포함할 수 있습니다.

로컬 `.my-agent-stack-denylist`에는 추가 비공개 표식을 한 줄에 하나씩 기록할 수 있습니다. 이 파일은 의도적으로 Git에서 무시되며 커밋해서는 안 됩니다.

<a id="installer-boundary"></a>
## 설치 도구 경계

- `plan`은 파일을 쓰지 않습니다.
- 비대화형 `install`에는 `--yes`가 필요합니다.
- 기존 경로의 내용이 다르면 `--force`를 명시하지 않는 한 실패합니다.
- 원본 구성 요소의 심볼릭 링크와 대상 상위 경로를 벗어나는 링크를 거부합니다.
- 설치 도구는 카탈로그 소유 파일만 복사하며, 다운로드한 훅을 실행하지 않습니다.
- 프로필과 영수증에는 자격 증명을 넣지 않습니다.
- 자동화 레시피는 설치 후에도 비활성 상태이며 예약되지 않습니다.
- 외부 시스템 변경은 버전 0.1 설치 도구의 범위에 포함하지 않습니다.

`--force`는 의도적으로 강한 옵션입니다. 사용하기 전에 출력된 계획의 모든 경로를 검토하세요. 변경 사항은 실제 에이전트 구성이 아닌 임시 대상에서 테스트해야 합니다.
