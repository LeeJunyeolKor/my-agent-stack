# 검증 계약

다음 명령을 실행합니다.

```bash
npm run verify
```

현재 이 명령은 다음 항목을 검사합니다.

- JavaScript 문법과 JSON 파싱
- 구성 요소, 에이전트, 프로바이더, 엔트리포인트, 이름 규칙의 불변 조건
- 필수 기능 확인과 명시적 제외 처리
- 결정론적 설치 계획과 파일 해시
- 임시 디렉터리에 선택한 항목만 설치되는지 여부
- 동일한 재설치의 멱등성
- 충돌 및 심볼릭 링크 경로 이탈 거부
- 자동화가 기본적으로 비활성화되는 안전장치
- 공개 안전성 패턴
- README의 카탈로그 항목 포함 여부

<a id="evidence-boundary"></a>
## 증거의 경계

검증을 통과했다는 것은 현재 체크아웃의 카탈로그와 로컬 설치 도구가 테스트 대상 계약을 충족한다는 뜻입니다. 다음 항목까지 증명하는 것은 아닙니다.

- 목록에 있는 모든 에이전트에서 동작이 동일하다는 것
- 실제 프로바이더 연결이나 인증이 성공한다는 것
- 자동화가 예약 또는 활성화되었거나 유용한 결과를 만들고 있다는 것
- 조직 정책을 검토하지 않아도 안전하게 사용할 수 있다는 것
- 공개된 패키지 레지스트리에서 설치할 수 있다는 것

해당 에이전트와 구성 요소 버전에 대해 현실적인 독립 동작 테스트가 기록되기 전까지 대상 호환성은 `unverified`로 유지합니다.
