# 티켓 상태

현재 환경에서 선택한 이슈 및 소스 제어 provider를 사용한다. 특정 트래커, 저장소 호스트, 워크플로 이름, 상태 식별자를 전제로 두지 않는다.

관찰 가능한 증거만으로 변경안을 도출한다.

- 브랜치나 열린 PR은 작업 중 단계를 뒷받침할 수 있다.
- 머지된 PR은 작업 완료 단계를 뒷받침할 수 있다.
- 증거가 없거나 모호하면 다음 상태로 전환하지 않는다.
- 어떤 증거도 이슈를 자동으로 이전 상태로 되돌리는 근거가 되지 않는다.

상태 이름을 하드코딩하지 말고 이슈에서 사용 가능한 전환을 조회한다. 로컬 정책이 권장 가능한 단계를 제한하더라도 브랜치와 PR 증거는 그대로 보여준다. 정책 상한은 권장안을 바꿀 뿐, 변경 권한을 부여하지 않는다.

먼저 이슈별 읽기 전용 미리보기를 제공한다. 현재 상태, 제안 상태, 증거, 정책, 누락된 필수 필드, 모호한 전환 후보를 보여준다. 사용자 선택을 한 번 요청한 뒤 개별 승인된 이슈만 변경한다. 필수 필드를 추정하거나 의미가 다른 전환 중 하나를 임의로 선택하지 않는다.

승인된 변경 후 provider 응답만으로 새 상태가 입증되지 않으면 다시 조회한다. 적용, 건너뜀, 실패 이슈를 구분해 보고한다. 인증 정보는 선택한 provider 또는 secret store에만 두며 스킬, 프로필, 출력, 로그에 기록하지 않는다.
