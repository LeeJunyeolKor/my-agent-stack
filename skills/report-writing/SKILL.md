# 결과 보고서 작성

보고서가 답해야 할 질문, 기간과 범위, 독자, 사용할 자료를 먼저 확인한다. 지정된 형식과 기존 문서가 있으면 유지한다. 템플릿이 없으면 핵심 결과, 조사 방법·범위, 결과의 근거, 후속 조치가 읽히게 구성한다.

[증거 기반 완료 판단](../evidence-first-delivery/SKILL.md)으로 각 주장의 확인 수준을 정하고, [기술 문서 작성](../technical-writing/SKILL.md)으로 표현을 다듬는다. 이 스킬은 보고서 구성·집계·저장을 소유하며 완료 상태의 기준을 별도로 만들지 않는다.

## 집계와 결과

- 수치는 대상, 기간, 단위와 분모를 함께 적는다. 중복 제거 기준과 표본 범위를 밝힌다.
- 조회 실패나 권한 부족, 누락된 페이지는 0건으로 계산하지 않는다. 성공적으로 확인한 범위와 집계에서 제외한 범위를 구분한다. 일부만 조회했으면 전체 총계라고 부르지 않는다.
- 실행 결과와 예정 작업을 구분한다. 검증 결과에는 환경·대상·명령 또는 시나리오·관찰값과 미검증 부분을 적는다.
- 결과는 독자가 판단할 단위로 묶고 근거를 해당 주장 가까이에 둔다. 미완료 후속 조치는 다음 확인 수단이나 결정할 사항을 적되 담당자·일정을 만들어 내지 않는다.

## 저장과 게시

요청한 경로와 형식으로 저장한다. 형식 변환이 필요하면 사용 가능한 전용 도구로 결과를 확인한다. 외부 게시를 명시적으로 요청받았을 때만 대상 공간과 문서를 확인해 실행한다. 저장·게시 응답이 모호하면 기존 결과를 조회해 중복을 피한다. 본문 변환이 있었으면 저장된 내용도 확인한다.

도구가 없으면 작성 가능한 초안을 제공하고 실행하지 못한 저장·변환·게시를 명시한다. 완료 보고에는 실제 파일 또는 확인한 링크와 남은 제한을 적는다.
