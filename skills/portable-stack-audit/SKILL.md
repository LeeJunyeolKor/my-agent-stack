# 이식 가능한 스택 점검

범위에 포함된 에이전트 위치만 조사한다. 발견한 각 스킬과 자동화에 다음 항목을 기록한다.

- 에이전트와 설치 위치
- 직접 설치 파일 또는 symbolic link
- 확인 가능한 경우 출처 또는 제작자
- 정상, 누락 또는 손상 상태
- 자체 제작, 서드파티, 조직 소유 또는 출처 불명
- 공개, 비식별 사례, 비공개 또는 검토 필요 권장안

파일명만으로 소유권을 추정하지 않는다. 라이선스와 공개 권리는 검증하기 전까지 알 수 없는 것으로 취급한다. 정상 symbolic link는 대상이 해석된다는 사실만 입증하며, 해당 자료를 다시 공개할 수 있다는 의미는 아니다.

기본 동작은 읽기 전용 보고서 작성이다. 끊어진 링크 제거, 모듈 복사, 에이전트 설정 변경, 콘텐츠 공개에는 각각 별도의 명시적 요청이 필요하다. 공개 산출물에서는 인증 정보, 내부 경로, 비공개 도메인, 티켓 식별자, 업무 샘플을 제거한다.
