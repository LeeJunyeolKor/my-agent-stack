# 일일 작업 요약

## 목적

선택한 소스 제어 프로바이더의 정보를 바탕으로 간결한 요약을 작성한다. 이슈 프로바이더가 설정되어 있고 읽기가 가능할 때만 이슈 맥락을 추가한다.

## 실행 절차

1. 요청한 기간의 사용자 관련 커밋, 브랜치, PR 활동을 수집한다.
2. 이슈 추적을 사용할 수 있다면 관계를 확인할 수 있는 활동만 이슈와 연결한다.
3. 완료한 작업, 진행 중인 작업, 차단된 작업, 확인이 필요한 항목을 구분한다.
4. 주요 진술을 각각 확인 가능한 근거와 연결한다.
5. 보고서를 게시하지 않고 반환한다. 메시징 프로바이더로 전송하는 작업은 별도로 확인받아야 한다.

## 실패 시 동작

예약 실행의 입력에 실질적인 변화가 없으면 알림을 보내지 않는다. 프로바이더를 사용할 수 없다면 누락된 정보 소스를 알리고, 남은 근거만으로도 유용한 요약을 작성할 수 있을 때만 계속한다.
