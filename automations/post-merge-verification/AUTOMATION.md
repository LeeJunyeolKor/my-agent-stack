# 병합 후 검증

## 목적

PR 근거를 후속 상태의 증명으로 재사용하지 않고 대상 브랜치의 병합 결과를 검증한다.

## 실행 절차

1. PR이 병합되었는지 확인하고 정확한 대상 리비전을 식별한다.
2. 격리되고 깨끗한 환경에서 해당 리비전을 체크아웃하거나 점검한다.
3. 저장소의 관련 검증 계약을 실행한다.
4. 관찰한 결과를 승인된 PR 기준선과 비교한다.
5. 병합 검증 결과를 배포 상태 및 프로덕션 런타임 상태와 구분하여 보고한다.

## 실패 시 동작

대상 리비전, 저장소 검증 명령어, 승인된 기준선을 확인할 수 없으면 중단한다. 배포 대상을 추측하거나 릴리스 상태를 변경하지 않는다.
