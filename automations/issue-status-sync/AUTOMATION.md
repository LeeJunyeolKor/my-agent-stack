# 이슈 상태 동기화

## 목적

이슈 추적기 상태를 현재 소스 제어 근거와 비교하고, 정책에서 허용하는 상태 전환을 사용자 확인 없이 실행하는 대신 제안한다.

## 실행 절차

1. 작업 범위에 지정된 이슈와 저장소를 식별한다.
2. 현재 이슈 상태, 브랜치 상태, 그리고 확인 가능한 경우 PR 상태를 조회한다.
3. 근거를 조직의 로컬 상태 전환 프로필과 비교한다.
4. 현재 상태, 근거, 전환 후보, 필수 필드를 제시한다.
5. 상태를 변경하기 직전에 확인을 요청한다.
6. 승인된 변경 후 이슈를 다시 조회하고 요청한 상태가 실제로 확인되는지 보고한다.

## 실패 시 동작

작업 공간, 이슈 식별 정보, 상태 전환 정책, 권한, 필수 필드가 확인되지 않으면 중단한다. 추측으로 다른 프로젝트나 저장소를 선택하지 않는다.
